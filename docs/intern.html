インターン募集要項

生成AI×Webシステム開発インターン募集（未経験OK）

生成AIを“仕事の道具”として使いながら、Webシステム開発案件の一部工程を担当していただきます。
実践で使う際のレクチャーや開発過程で社員からレビューを受けられるので学びもあって安心です。

このような方向け

  • AIを使った開発にチャレンジしたい
  • エンジニア未経験でもOK
  • 物事を整理して、タスクに落とすのが得意/好き
  • “作って動かす”のが好き/興味がある
  • 実装だけでなく「誰のどんな課題をどう解くか」など顧客ニーズの理解に興味がある

やっていただく事（例）

  • お客様要望の整理・タスク分解
  • AIへの指示設計（プロンプト改善）→ 実装（AI生成コードの修正・統合含む）→ 動作確認
  • 自社開発のツールのテスト・改善提案

このインターンで得られる事

  • 企画立案〜要件整理〜実装〜検証までの、AI開発の実務フローを体験。
  • AIプロンプト設計 / 実装スキルが身につく。
  • 小規模チーム（2~4名）だからこそ、複雑なルールや縛りが少なく実務者との距離が近く、フィードバックがすぐにもらえる環境。
  • 代表はSaaSベンチャーで成長フェーズを牽引した経験があり、「価値創造」「マーケティング」「データドリブン」など視座の高いフィードバックも日常的に得られる。
  • 創世記/成長期のベンチャー企業を体感できる。

条件

  • 期間：1〜3ヶ月（延長あり/長期歓迎）
  • 稼働：週2〜3日、1日4h〜 試験や就職活動など状況の相談に乗ります
  • 働き方：リモートワーク勤務＋月に数回オフライン会議あり（都内WeWorkで開催）
  • 報酬：時給1,400円〜スキルにより昇給あり
  • ツール：Slack / Google Workspace / GitHub / Cursor / Claude Code / VSCode など

選考フロー

フォーム → カジュアル面談（オンライン 30〜60分）
↓
AI実装の簡単な課題提出（60〜120分）
↓
最終面談（オフライン） → 決定
